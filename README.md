# ASL Book Signer 📖

A web application to display ASL (American Sign Language) diagrams and signs for words you type. Perfect for signing books and other content to your deaf loved ones!

## Features

- **Fingerspelling Mode**: Shows individual letter signs for spelling out words
- **Word Signs Mode**: Displays common ASL word signs with links to full demonstrations
- **Clean, User-Friendly Interface**: Easy to use with real-time sign display
- **Responsive Design**: Works on desktop and mobile devices

## How to Use

1. Open `index.html` in your web browser
2. Choose your mode:
   - **Fingerspelling**: Shows letter-by-letter signs (great for names, specific words, or spelling)
   - **Word Signs**: Shows full word signs with links to sign demonstrations
3. Type any word or sentence in the text box
4. ASL signs will appear below in real-time
5. Use the signs to practice signing books to your son!

## Getting Started

Simply open the `index.html` file in any modern web browser:

```bash
# On Linux/Mac
open index.html

# On Windows
start index.html
```

Or drag and drop the `index.html` file into your browser window.

## Tips for Signing Books

- Start with fingerspelling mode to learn individual letters
- Use word signs mode for common words to sign more naturally
- Practice each sign before showing your son
- Take your time - clarity is more important than speed
- Many books can be signed using a combination of fingerspelling and word signs
